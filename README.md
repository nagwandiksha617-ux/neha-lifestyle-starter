# NEHA Lifestyle Starter

Create a new React + TypeScript project for the brand “NEHA LIFESTYLE.” Set up only a clean, premium fashion e-commerce starter structure, including a root-level /public folder. Do not build the full site, add stock images, generate product images, or populate product content. The future categories are Bags, Clutches, and Jewellery.

This project was built with [Lovable](https://lovable.dev).
